# Controle de Amostras de Óleo

Aplicativo Streamlit com uma página inicial única e duas áreas:

- Registro de Coleta
- Retorno da Amostra

O arquivo principal do Streamlit continua sendo `streamlit_app.py`.

## Credenciais

Configure `GOOGLE_TOKEN` e, opcionalmente, `GOOGLE_CLIENT_SECRET` nos Secrets do Streamlit Community Cloud. Não publique tokens reais no GitHub.
